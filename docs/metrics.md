# 성장 상권 지표 설계서 (P1, v2)

> **Answer First**
> "3년 뒤 성장할 상권"을 **새로 들어간 커피·베이커리 점포 하나가 버는 매출(점포당 매출)이 앞으로 3년간 서울 평균보다 빠르게 늘어날 상권**으로 정의한다.
> 점포당 매출을 `결제건수 × 객단가 ÷ 점포수`로 분해하고, 각 항을 **수요 · 지출 · 경쟁 · 선행 신호** 4개 축, 9개 지표로 측정한다.
> 가중치는 논리 초안을 **코로나 영향을 걷어낸 백테스트로 검증해 확정**하고, 출점이 불가능하거나 위험한 상권은 점수와 별개의 **진입 필터**로 먼저 거른다.

v1 → v2 변경: 독립 리뷰(PE·데이터 관점)에서 지적된 ① 매출 CAGR 중복 반영 ② 과거 데이터인 D축을 "미래"로 부른 점과 범주형 상권변화지표의 방향 오류 ③ 상권 성장과 점포 수익의 괴리, 코로나 회복 학습 문제를 고쳤다. (변경 이력은 9장)

## 1. 목표 변수 — "성장"이란 무엇인가

| 구분 | 정의 | 왜 |
|---|---|---|
| **주 목표** | 커피-음료 + 제과점 **점포당 추정매출**의 3년 CAGR − 서울 전체 동일 값 | PE가 사는 것은 상권이 아니라 **점포 하나의 매출**. 상권 매출이 늘어도 점포가 더 빨리 늘면 우리 몫은 줄어든다 |
| 보조 목표 | 같은 업종 **상권 전체 추정매출**의 3년 CAGR − 서울 전체 | 시장 자체의 성장. 주 목표와 순위가 크게 다르면 원인을 해석 |
| 단위 | 서울시 상권분석서비스의 상권(상권코드), 분기 | |
| 서울 대비 초과분 | 물가·경기 영향을 상쇄하고 상권 자체의 힘만 남김 | |

**성장률 계산 규칙 (모든 지표 공통)**
- CAGR은 분기 하나가 아니라 **4분기 평균끼리** 비교한다 (계절성·분기 노이즈 제거).
- 기초값이 매우 작은 상권의 과장된 성장률을 막기 위해 5장 "최소 시장 규모" 필터를 먼저 적용한다.
- 극단값은 상·하위 2.5%에서 절단(winsorize)한 뒤 **백분위 순위(0~100)** 로 표준화한다. z-score를 쓰지 않는 이유: 성장률 분포가 한쪽으로 크게 치우쳐 평균·표준편차가 왜곡되기 때문.

## 2. 지표 트리 (MECE)

### 2-1. 분해식

```
점포당 매출  =  결제건수  ×  건당 매출(객단가)  ÷  점포수
               (수요 A)       (지출 B)            (경쟁 C)

점포당 매출 성장률 ≈ 결제건수 성장률 + 객단가 성장률 − 점포수 성장률
```

각 항은 서로 다른 데이터(인구·결제건수 / 결제금액÷건수 / 점포수)로 측정되므로 **같은 값을 두 번 세지 않는다(ME)**. 세 항의 합이 목표 변수 전체이므로 **빠진 동인이 없다(CE)**. 여기에 **아직 결과에 반영되지 않은 선행 신호(D)** 를 더한다.

### 2-2. 지표

| 축 | 코드 | 지표 | 계산식 | 방향 | 데이터셋 (서울시 상권분석서비스) |
|---|---|---|---|---|---|
| **A 수요**<br>결제건수의 원천 | A1 | 유동인구 성장 | 길단위 유동인구 3년 CAGR | + | 길단위인구-상권 |
| | A2 | 고정 배후수요 성장 | (직장인구 + 상주인구) 3년 CAGR | + | 직장인구-상권, 상주인구-상권 |
| | A3 | 업종 전환율 변화 | 커피·제과 결제건수 ÷ 유동인구, 3년 변화 | + | 추정매출-상권, 길단위인구-상권 |
| **B 지출**<br>객단가 | B1 | 객단가 성장 | 커피·제과 (매출금액 ÷ 매출건수) 3년 CAGR | + | 추정매출-상권 |
| | B2 | 핵심 고객층 이동 | 커피·제과 매출 중 20~30대 비중 변화(%p) | + | 추정매출-상권 |
| **C 경쟁**<br>점포수 | C1 | 경쟁 점포 증가 | 커피·제과 점포수 3년 CAGR | **−** | 점포-상권 |
| | C2 | 업종 생존 안정성 | 커피·제과 폐업률 (최근 4분기 평균) | **−** | 점포-상권 |
| **D 선행 신호**<br>결과보다 먼저 움직이는 것 | D1 | 프랜차이즈 진입 신호 | 커피·제과 점포 중 프랜차이즈 비중 변화(%p) | + | 점포-상권 |
| | D2 | 상권 활성화 신호 | 커피·제과 **외** 전 업종 개업률 (최근 4분기 평균) | + | 점포-상권 |

**D축을 "미래"가 아닌 "선행 신호"라고 부르는 이유**: D1·D2도 과거 데이터다. 다만 매출이라는 **결과**가 아니라, 결과보다 먼저 움직이는 **의사결정**(대형 프랜차이즈의 입지 판단, 다른 업종 창업자들의 진입)을 측정한다. 프랜차이즈 본사는 자체 상권 분석으로 출점하므로 비중 증가는 "전문가가 먼저 베팅한 상권"이라는 신호다.

**점수에 넣지 않는 것과 이유**

| 항목 | 처리 | 이유 |
|---|---|---|
| 업종 매출 모멘텀 (과거 3년 매출 CAGR) | 점수 제외, **통제 변수**로만 보고 | 목표 변수의 과거값이다. A·B·C의 합과 같은 정보이므로 넣으면 중복이고, 평균회귀 때문에 미래 성장과 음(−)의 상관이 나올 수도 있다. 백테스트에서 상관을 별도로 보고한다 |
| 점포당 매출 **수준** | 점수 제외, 손익(P5)에서 사용 | 수준이 높으면 신규 진입을 부르는 양면성이 있어 방향을 미리 정할 수 없다 |
| 소득·소비 수준 | 점수 제외, 최종 후보 3곳의 **컨셉 적합성** 판단에 사용 | 성장이 아닌 수준 지표라 목표 변수와 단위가 맞지 않는다 |
| 상권변화지표 | **진입 필터에서만** 사용 (5장) | 운영·폐업 점포의 영업기간으로 나눈 4개 범주(LL 다이나믹 / LH 상권확장 / HL 상권축소 / HH 정체)라 순서가 없는 척도다. 점수화하면 방향을 정할 수 없고, 필터와 이중 반영된다 |
| 교통·재개발 계획 | 최종 후보 3곳만 **정성 검토** (출처 명시) | 상권분석서비스 밖 자료이고 전체 상권에 일관되게 수치화할 수 없다 |
| 임대료 | **진입 필터** + 손익(P5) | 성장성과 수익성은 다른 질문이지만, 임대료 급등은 PE 관점의 하방 위험이므로 필터로 막는다 |

### 2-3. 남은 겹침과 확인 방법

| 겹칠 수 있는 쌍 | 이유 | 처리 |
|---|---|---|
| A1 유동인구 ↔ A2 직장+상주 | 길단위 유동인구에는 직장인·주민의 이동도 포함 | 상관 \|r\| ≥ 0.8이면 A2를 "A1으로 설명되지 않는 부분(잔차)"으로 대체 |
| A3 전환율 ↔ C1 점포수 | 점포가 늘면 결제건수도 늘어 전환율이 오를 수 있음 | 상관 확인. 높으면 A3를 점포당 결제건수로 바꾸지 않고(= 목표 변수와 겹침) 제거 |
| C2 폐업률 ↔ D2 타 업종 개업률 | 상권 전체의 교체율이 높으면 둘 다 높음 | 서로 다른 업종 집합이라 구조적 중복은 없음. 상관만 확인 |

## 3. 가중치 (초안 → 백테스트로 확정)

### 3-1. 논리 기반 초안 (기본안 W0)

| 축 | 가중치 | 근거 |
|---|---|---|
| A 수요 | 35% | 커피·베이커리는 생활밀착·저가 반복 구매 업종. 결제건수가 매출 변동의 가장 큰 원천 |
| B 지출 | 20% | 커피 객단가는 업종 특성상 상권 간 차이가 수요·경쟁보다 작음 |
| C 경쟁 | 30% | 진입장벽이 낮아 점포 증가가 빠름. 분해식에서 점당 매출에 직접 마이너스로 작용 |
| D 선행 | 15% | 간접 신호라 측정 오차가 가장 큼 → 가장 작은 비중 |

축 안의 지표는 **동일 가중**으로 시작한다.

> B 비중 20%는 "커피 객단가의 상권 간 편차가 작다"는 가정에 기반한다. P2 데이터에서 객단가 CAGR의 상권 간 분산을 확인해 가정이 틀리면 수정한다.

### 3-2. 비교할 대안

| 안 | A | B | C | D | 의도 |
|---|---|---|---|---|---|
| W0 기본 | 35 | 20 | 30 | 15 | 분해식 논리 |
| W1 동일 | 25 | 25 | 25 | 25 | 사전 판단 없는 기준선 |
| W2 수요 중심 | 45 | 20 | 20 | 15 | "사람이 모이면 팔린다" |
| W3 경쟁 중심 | 25 | 20 | 40 | 15 | "경쟁이 적어야 남는다" |
| W4 선행 제외 | 40 | 25 | 35 | 0 | D축이 실제로 예측에 기여하는지 확인 |
| W5 데이터 기반 | — | — | — | — | 백테스트 회귀계수 역산 (**참고용**, 채택 안 함) |

### 3-3. 확정 규칙
1. 6장 백테스트에서 주 목표에 대한 **Spearman 순위상관이 가장 높은 안**을 채택한다.
2. 1등과 W0의 차이가 0.05 미만이면 **설명 가능한 W0을 유지**한다 (과적합 방지).
3. W4가 W0보다 낫거나 같으면 D축을 제거하고 3축으로 간다. 정직하게 "선행 신호는 예측력이 없었다"고 쓴다.
4. W5는 각 축의 실제 기여도를 보여주는 참고 차트로만 쓴다.

## 4. 표준화와 합산

```
각 지표: 원값 → 2.5%/97.5% 절단 → 서울 전체 상권 내 백분위(0~100)
         방향이 − 인 지표는 (100 − 백분위)
축 점수 = 축 안 지표 평균
성장 점수 = Σ (축 가중치 × 축 점수)     → 0~100점
```

## 5. 진입 필터 (점수 계산 전에 적용)

| 필터 | 기준 | 이유 |
|---|---|---|
| 최소 시장 규모 | 커피·제과 연 매출이 서울 상권 하위 30% 미만 제외 | 작은 기반의 성장률 과장 방지 (10억 → 20억 = 100%) |
| 데이터 신뢰도 | 최근 4분기 커피·제과 점포 3개 미만 제외 | 점포당 매출이 점포 1~2개에 좌우됨 |
| 쇠퇴 구조 | 상권변화지표 'HL 상권축소' 제외 | 영업 중인 점포는 오래됐는데 폐업 점포는 빨리 닫힘 = 신규 진입자가 버티지 못하는 구조 |
| 상권 유형 | 관광특구는 별도 검토 | 외국인 관광 수요에 좌우돼 일반 상권과 비교 불가 |
| 임대료 급등 | 상위 10개 상권 단계에서, 해당 지역 상가 임대료 상승률이 서울 상위 20%인 곳은 경고 표시 후 3곳 비교에서 감점 사유로 명시 | 젠트리피케이션 = 점포 경제성의 하방 위험. 출처: 한국부동산원 상업용부동산 임대동향(서울열린데이터 외 자료, 출처 별도 명시) |

## 6. 정합성 검증 (P3에서 실행)

### 6-1. 백테스트 설계 — 코로나 회복을 "성장"으로 학습하지 않기

2020~2021년은 매출·유동인구가 비정상적으로 낮았다. 이 구간을 시작점으로 잡으면 피해가 컸던 상권(도심·대학가)이 "고성장"으로 보인다. 그래서 **양 끝점을 모두 정상 시기의 4분기 평균**으로 잡는다.

| 구간 | 기간 (4분기 평균끼리 비교) | 용도 |
|---|---|---|
| 지표 계산 구간 | 2019년 평균 → 2022년 평균 | 코로나 전후를 끝점으로 → 코로나를 지나고도 남은 **구조적 변화**만 측정 |
| 정답 구간 | 2022년 평균 → 최근 4분기 평균 (약 2.5~3년) | 실제 점포당 매출 성장 (주 목표) |
| 최종 추천 | 같은 공식을 최근 3년(최근 4분기 평균 vs 3년 전 4분기 평균)에 적용 | |

- **미래 정보 누출 금지**: 지표 계산에는 2022년까지 데이터만 사용.
- **회복률 점검**: 2022년 평균이 2019년 평균의 몇 %까지 회복했는지 상권별로 계산. 회복률이 서울 하위 10%인 상권은 정답 구간 성장이 "늦은 회복"일 수 있으므로 결과 해석 시 표시.

### 6-2. 검증 항목

| 검증 | 방법 | 통과 기준 | 실패 시 |
|---|---|---|---|
| ① 방향 일치 | 각 지표와 주 목표의 단순 Spearman 상관 부호 | 2-2의 방향과 일치 | 지표 제거, 또는 반대 방향의 근거를 찾아 기록 |
| ② 중복 제거 | 9개 지표 상관행렬 히트맵 | 모든 쌍 \|r\| < 0.8 | 2-3의 규칙 적용 |
| ③ 예측력 | 성장 점수 순위 vs 실제 주 목표 순위 | ρ > 0.3, **상위 20% 상권의 실제 성장이 하위 20%보다 높음** (차이와 검정 결과 제시) | 가중치 재조정, 지표 교체 |
| ④ 안정성 | 끝점 정렬을 바꿔 재계산 (연평균 대신 하반기 평균 등) + 상권 부트스트랩 | 상위 10개 중 6개 이상 유지 | 변동 큰 지표를 더 긴 평균으로 평활 |
| ⑤ 모멘텀 대비 | 과거 매출 CAGR 하나만으로 순위를 매긴 경우와 비교 | 성장 점수의 ρ가 더 높음 | 높지 않다면 "지표 체계가 단순 추세 추종보다 낫지 않다" — 지표 재설계 |

⑤는 "그냥 최근에 잘 된 상권을 고른 것 아니냐"는 PE의 질문에 대한 답이다.
