# 인테리어 컨셉 (P5-2)

> 모든 공통 수치(면적·좌석·운영시간·객단가·매출 구성)는 `docs/concept.md` "공통 가정" 표를 인용한다.

## Answer First
**30평·36석 매장을 "낮에는 밝은 베이커리, 17시 이후에는 조도를 낮춘 디저트 라운지"로 전환되는 공간으로 만들어, 매출의 40.2%가 17~21시에 몰리는 망원역 1번 상권의 저녁 수요를 잡는다 [E16].**

## 1. 공간 컨셉 — "해 질 녘부터 붐비는 베이커리 라운지"
- 근거: 커피·제과 매출 17~21시 40.2% (서울 21.5%), 06~11시 5.3% [E16] → 아침형 테이크아웃 매장이 아니라 저녁에 머무는 매장 (I-2).
- 고객: 20~30대 70.0%, 여성 72.6% [E17], 주말 매출 37.0% [E18] → 혼자 쉬는 평일 저녁(페르소나 A)과 사진 찍는 주말 모임(페르소나 B)을 한 공간에서 받는다.
- 주인공은 빵: 상권 제과점 5개, 제과 매출은 커피의 6.5% [E19] → 입구에서 바로 보이는 오픈키친·진열대로 "베이커리 카페"임을 알린다 (I-3).

## 3. 저녁 조명·무드 전략 (17시 이후 전환)
- 11~17시: 3,500K 밝은 주광, 진열대 집중 조명 → 빵이 잘 보이는 "베이커리 모드".
- 17시 전환: 전체 조도 약 50%로 낮추고 2,700K 웜톤 펜던트·테이블 캔들 조명, 음악 BPM 낮춤 → "라운지 모드". 시간대 매출 17~22시 55% 가정을 공간으로 뒷받침 [E16].
- 17시부터 진열대는 "이브닝 디저트 코스" 플레이트 진열로 교체, 메뉴 보드도 저녁판으로 전환 (menu.md 연계).

## 4. 베이커리 오픈키친·진열
- 유리벽 오픈키친을 입구 동선 정면에 배치 → 굽는 장면 자체가 간판 역할 (제과점 공백 상권 [E19]).
- 진열대는 눈높이 3단: 상단 시그니처(소금버터 크루아상), 중단 볼륨(타르트·치즈케이크), 하단 구움과자(휘낭시에) → 객단가 15,000원 세트 구성 유도 [E12].

## 5. 테이크아웃 동선
- 입구 → ①진열·주문 → 픽업 → 출구의 일방향 루프로, 테이크아웃 고객(객수의 40% 가정)이 좌석존을 지나지 않게 분리.
- 주말 피크(13~19시) 대기줄은 진열대 앞에 서게 해 대기 시간이 곧 빵 추가 구매 시간이 되도록 설계 [E18].

## 6. 차별화 포인트 3개
1. **시간대 전환 공간**: 같은 30평이 17시를 기점으로 베이커리 → 디저트 라운지로 바뀐다 — 저녁 매출 비중 서울의 약 2배 상권에 맞춤 [E16] (I-2).
2. **보이는 베이커리**: 경쟁 커피 27개 대비 제과점 5개인 상권에서 오픈키친으로 "빵집"임을 시각화 [E13, E19] (I-3).
3. **1인 바 + 그룹 테이블 혼합 좌석**: 평일 저녁 1인(A)과 주말 모임(B)을 36석 안에서 모두 수용 [E17, E18].
