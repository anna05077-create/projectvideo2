# 2분 발표 영상 대본 (Answer First, v2 — 채점 피드백 반영)

> 영상: site/motion.html (HTML 모션 영상 + 내레이션), 페이지 상단에 임베드. 수치는 docs/evidence.md ID와 일치.
> 모션 스타일(참고: airoasting.com 모션 디자인): 키네틱 타이포그래피 · 숫자 카운터 · 순위 카운트다운 · 데이터 스토리 막대 · 순서도 · 다이내믹 자막 · 엔드 카드. 원칙: 장면마다 주인공 하나(Staging).

| # | 화면(모션) | 내레이션 |
|---|---|---|
| S1 | 키네틱 타이포 + 숫자 카운터 | 결론부터 말씀드립니다. 마포구 망원역 1번 상권에, 저녁에 붐비는 베이커리 라운지를 여십시오. 기본 시나리오 월 영업이익 약 이천칠백만 원, 투자금 사억 오천만 원은 약 십삼 개월에 회수합니다. |
| S2 | 순위 카운트다운 (1,650 → 630 → 후보) | 서울시 상권분석서비스로 육백삼십 개 상권을 점수화하고, 과거 데이터로 미래를 맞혀 봤습니다. 최근에 뜬 상권을 따라가는 전략은 맞히지 못했습니다. 유효한 신호는 카페가 이미 모인 집적지였습니다. |
| S3 | 데이터 스토리 막대 (시간대) | 망원역 1번은 유동인구가 십칠 퍼센트 늘었는데 경쟁 점포는 십칠 퍼센트 줄었습니다. 그리고 매출의 사십 퍼센트가 저녁 다섯 시부터 아홉 시에 나옵니다. 서울 평균의 두 배입니다. |
| S4 | 숫자 대비 (8.3% vs 28.9%) | 이삼십 대가 매출의 칠십 퍼센트, 객단가는 서울의 1.8배입니다. 그런데 베이커리 매출은 커피의 8퍼센트로, 서울 평균 29퍼센트에 한참 못 미칩니다. 베이커리가 비어 있습니다. |
| S5 | 순서도 (타깃→공간→메뉴→손익) | 그래서 베이커리 오픈키친을 입구에 두고, 오전 열한 시부터 밤 열 시까지, 저녁 디저트 코스로 승부합니다. |
| S6 | 엔드 카드 | 객수가 이십 퍼센트 줄어도 흑자입니다. 첫 육 개월 실적으로 이호점을 판단하십시오. 망원역 1번, 베이커리 라운지를 제안드립니다. |
