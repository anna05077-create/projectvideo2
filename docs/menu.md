# 메뉴 포트폴리오 (P5-3)

> 객단가 15,000원, 매출 구성(베이커리·디저트 50% / 커피 35% / 논커피·기타 15%), 원가율 32%, 운영 11:00~22:00은 `docs/concept.md` "공통 가정" 표를 인용한다. 가격·품목별 원가율은 메뉴 설계용 가정이다.

## Answer First
**빵·디저트가 매출의 절반을 만들고, 17시 이후 "이브닝 디저트 코스(14,000원, 음료 동반 시 1인 약 18,000~19,000원)"로 저녁 객단가를 끌어올려 낮(약 12,000원)과 가중평균 15,000원 수준을 맞추는 13개 메뉴 포트폴리오다 — 가중평균 객단가 15,020원, 가중 원가율 31.8%로 공통 가정(15,000원·32%)과 일치한다.**

## 1. 설계 논리 (페르소나·인사이트 연결)
- **I-3 베이커리 공백**: 제과 매출이 커피의 6.5%, 제과점 5개 [E19] → 베이커리·디저트를 매출 50%의 주력으로.
- **I-2 저녁 디저트 상권**: 17~21시 매출 40.2% [E16], 객단가 15,443원 [E12] → 저녁 전용 디저트 코스로 "커피 + 디저트" 구매를 상품화.
- **페르소나 A** (평일 18~21시, 1인 15,000원대): 디저트 코스 + 논커피/디카페인. 여성 72.6% [E17] → 디카페인·밀크티 라인 확보.
- **페르소나 B** (주말 13~19시): 시그니처 빵 + 커피 2잔 + 테이크아웃 빵(깜빠뉴·휘낭시에) [E18].

- **가중평균 객단가 = 1,502,000원 ÷ 100건 = 15,020원** ≈ 공통 가정 15,000원 (상권 15,443원 [E12]).

- 매출 구성 50.0 / 34.8 / 15.2% ≈ 공통 가정 50 / 35 / 15%.

## 4. 시간대 운영
- **11~17시 (매출 45% 가정)**: 갓 구운 크루아상·깜빠뉴 + 아메리카노/라떼, 주말 B 테이크아웃 중심 [E18].
- **17~22시 (매출 55% 가정)**: 이브닝 디저트 코스 + 디카페인·밀크티, 진열대·메뉴보드 저녁판 전환 (interior.md 3절) [E16].
